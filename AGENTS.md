# Repository instructions

- This repository is an independent clean-room toolkit built from public Claude
  Code hook interfaces and general software-engineering principles.
- Use only synthetic examples and public documentation.
- Never add employer material, production payloads, internal identifiers,
  credentials, personal data, or copied history.
- Keep hook decisions deterministic and test the deny, ask, and allow paths.
- Run `npm run check` and the public-repository scanner before publishing.
- Do not commit directly to `main`; publish reviewed commits from a release branch.
